# 后端架构（当前）

> **更新：2026-05-28**  
> 详细 SSOT：[docs/dev/kratos-migration.md](../docs/dev/kratos-migration.md) · 运行时：[docs/dev/moe-social-runtime.md](../docs/dev/moe-social-runtime.md)

## 分层（生产单进程）

```text
客户端 → Kratos HTTP :8888 → internal/service → internal/biz → internal/data → MySQL/Redis
       → Kratos gRPC  :8080 → internal/server/moegrpc → service → biz
```

| 层 | 职责 |
|----|------|
| **api/moehttp** | 存量 HTTP 路由适配（263 compat）；Kratos `ctx.Bind` |
| **internal/service** | 应用服务编排，供 HTTP/gRPC 调用 |
| **internal/biz** | 业务逻辑 SSOT |
| **internal/data** | 持久化（P4-D，按域 repo） |
| **rpc/bootstrap** | MoeAdmin / Bot gRPC 装配（**无** Super service） |

**不再使用**：`api/internal/logic`、`rpc/internal/logic`、对外 go-zero `rest` / `Super` gRPC。
