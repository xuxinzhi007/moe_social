## 分层（生产单进程）

```text
客户端 → Kratos HTTP :8888
         ├─ RegisterProtoHTTP（官方 *_http.pb.go，17 域）
         ├─ RegisterCompatHTTP（httplegacy 存量，逐域删除）
         └─ RegisterOpsHTTP
       → internal/service → internal/biz → internal/data → MySQL/Redis
       → Kratos gRPC :8080 → internal/server/grpc → service → biz
```

| 层 | 职责 |
|----|------|
| **api/\<domain\>/v1/*.proto** | HTTP/gRPC 契约 SSOT（含 `google.api.http`） |
| **internal/server/http_proto.go** | 官方 `Register*HTTPServer` 装配 |
| **internal/server/httplegacy/** | 存量 compat 适配（`BaseResp` JSON，逐域缩短） |
| **internal/service** | 应用服务编排，供 HTTP/gRPC 调用 |
| **internal/biz** | 业务逻辑 SSOT |
| **internal/data** | 持久化（按域 repo） |
| **internal/apilegacy/** | 过渡 gw/common（随 compat 退役） |
| **internal/legacy/types/** | 存量 goctl JSON 类型（compat 用） |

**不再使用**：`api/internal/logic`、对外 go-zero `rest`、Super gRPC。
