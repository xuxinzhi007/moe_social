# 后端架构（当前）

> 本文档已精简为**当前有效**说明；历史「API 直连 DB」描述已作废。

## 分层

```
客户端 → API (:8888) → RPC (:8080) → PostgreSQL / Redis
```

| 层 | 职责 |
|----|------|
| **API** | HTTP 路由、JWT 鉴权、请求/响应适配；**不**持有 GORM/DB |
| **RPC** | 业务逻辑、数据库访问、记忆 embedding、Bot 调度等 |
| **pkg/moe** | Moe Brain / Runtime / 工具编排（被 RPC/API logic 调用） |
