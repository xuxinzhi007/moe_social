> 详细 SSOT：[docs/dev/kratos-migration.md](../docs/dev/kratos-migration.md) · 审计：[docs/dev/kratos-architecture-audit.md](../docs/dev/kratos-architecture-audit.md)

## 分层（生产单进程 · HTTP 双轨余量小）

```text
客户端 → Kratos HTTP :8888
         ├─ corsFilter + compatEnvelopeFilter + EnvelopeResponseEncoder
         ├─ RegisterProtoHTTP（官方 *_http.pb.go，227 路由 / 18 域）
         ├─ RegisterCompatHTTP（httplegacy 存量，45 活跃路由）
         ├─ RegisterBridgeHTTP（swagger 三件套，3 路由）
         └─ RegisterOpsHTTP（/health、/migration 等）
       → internal/server/grpc/<domain>/ → internal/service → biz → data
       → Kratos gRPC :8080 → internal/server/grpc → service → biz
```

| 响应格式 | 路由类型 | 对外形状 |
|----------|----------|----------|
| Proto 信封 | `Register*HTTPServer` | `{code,message,success,...protoFields}` |
| Compat（压平后） | `httplegacy/*_compat` | 同上（`compat_envelope.go` 合并 `data`） |

Flutter 解析：`lib/services/api_response.dart`（仍兼容历史 `data` 嵌套）。

| 层 | 职责 |
|----|------|
| **api/\<domain\>/v1/*.proto** | HTTP/gRPC 契约 SSOT（含 `google.api.http`） |
| **internal/server/http_proto.go** | 官方 `Register*HTTPServer` 装配（19 次注册） |
| **internal/server/httplegacy/** | 存量 compat（45 条；P2 平台域等 + OAuth/SSE/图片） |
| **internal/server/grpc/** | proto HTTP 薄适配（`adminapp`、`llm`、`vipplans`、`content`…） |
| **internal/service** | 应用服务编排 |
| **internal/biz** | 业务逻辑 SSOT |
| **internal/data** | 持久化（按域 repo） |
| **internal/apilegacy/** | swagger bridge、过渡 gw（随 D4 退役） |
| **internal/legacy/types/** | 存量 goctl JSON 类型（compat 死代码仍引用） |

**不再使用**：`api/internal/logic`、对外 go-zero `rest`、Super gRPC。
