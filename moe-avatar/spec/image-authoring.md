# Moe Avatar — 图片规则与导入适配

> **核心结论**：Spec 约束的是 **模板对齐（格、锚点、分层）**，**不是像素风**。  
> 软 Q 版、抗锯齿、更高分辨率都可以，只要进编辑器后 **套在同一人偶模板上** 导出。

## 1. 两种美术来源

| 来源 | 做法 | 适用 |
|------|------|------|
| **官方美术** | 按 Spec 直接在模板上画 walk/idle sheet | 商城、默认形象 |
| **用户自定义图** | 导入 PNG → 编辑器对齐模板 → 导出层 | UGC / 社区包（远期） |

两种方式 **输出格式相同**：符合 manifest 的 layer PNG，App 不关心图是怎么来的。

## 2. 必须满足什么（才能「完美适配」）

### 2.1 格式

- PNG，**RGBA**，透明区域 truly alpha=0（不要假透明黑底）。
- 每个动画一张 sheet：**总尺寸 = cellSize × 列数 , cellSize × 4 行**。
- .walk：9×4 格；idle：2×4 格（v1）。

### 2.2 对齐（比画风更重要）

导入任意图片时，编辑器做这些事：

1. **缩放** — 统一 fit 到 cell 内「身体包围盒」（不撑破格线）。
2. **锚点对齐** — 脚底落 `origin`，头中心落 `headCenter`（见 Spec）。
3. **方向** — 若只有正面一张图，v1 可 **复制到 down 行**，left/right 用镜像；walk 帧可 duplicate + 轻微位移（编辑器辅助）。
4. **z 槽** — 只保留该槽位应出现的像素（上衣不画头，帽不画脸）。

未通过校验的层 **不能进官方包**（导出报错列表）。

### 2.3 画风（Moe 官方）

| 允许 | 不建议 |
|------|--------|
| 软边 Q 版、渐变、轻微描边 | 强制 1px 像素硬边（除非刻意复古） |
| cellSize 128 或 256 | 无格的自由尺寸贴纸 |
| 与 `character/head.png` 比例一致 | 与 body 比例差太大的写实立绘 |

现有参考：`assets/pet/character/` 分层约 **1600×2848** 是 **换衣间 A 方案单图**；  
**动画 sheet 方案**需重新在 **128×128 格** 上重绘或从模型采样，不能直接把 1600 图塞进 walk 格而不缩放。

## 3. 和 LPC 一样的工作流，不同的画风

```text
         ┌─────────────────┐
         │  Moe 人偶模板    │  ← 透明底 · 128 格 · 锚点十字
         │  (mannequin)    │
         └────────┬────────┘
                  │ 导入 / 手绘
     ┌────────────┼────────────┐
     ▼            ▼            ▼
  top_xxx     bottom_xxx    hat_xxx   … 各槽 walk/idle sheet
     │            │            │
     └────────────┴────────────┘
                  │ 校验 + 导出
                  ▼
           manifest.json + layers/ + thumbs/
```

ULPC Generator 做的是同一件事，只是默认 **64px 像素素材库**。  
我们编辑器默认加载 **Moe 官方底模 + 软 Q 预览**，导入图 **snap 到锚点** 即可。

## 4. 单品缩略图（换衣间列表）

**只展示该部件**，不整身合成：

- 文件：`thumbs/{item_id}.png`
- 内容：该层 **idle · down · 第 0 帧** 裁切（128×128 或缩到 64 显示）
- 由编辑器导出时自动生成

## 5. 从现有资源迁移

| 现有 | 迁移到 Moe Avatar v1 |
|------|----------------------|
| `clothes/top_basic.png` 单张 | 需在模板上重排为 `top_basic_walk/idle` sheet，或编辑器「单图 → 假动画」向导 |
| `lpc/layers/*.png` 64px | 可升采样到 128 作过渡；正式包应重绘软 Q |
| ULPC 某上衣 walk.png | 可 **临时** 导入编辑器对齐验证流程；**官方包不用 ULPC 图** |

## 6. 校验清单（导出前）

- [ ] walk / idle 宽高 = 列×cell、4×cell  
- [ ] 透明底无黑边  
- [ ] down idle 帧 0 锚点偏差 ≤ 2px  
- [ ] 与其他已选层叠放无穿模（编辑器预览）  
- [ ] 每个 slot id 有 thumb  
- [ ] manifest `specVersion` 与 App 支持版本一致  

## 7. 常见问题

**Q：必须像素风吗？**  
A：**不必须。** 必须的是格、锚点、槽位、动画布局。

**Q：用户上传一张 JPG 头像能当衣服吗？**  
A：v1 不支持任意贴图；需进编辑器裁切、抠图、对齐槽位后导出 PNG layer。否则无法保证与小家 walk 动画一致。

**Q：和 A 方案（1600 贴纸）关系？**  
A：A 方案是 **单 pose + 锚点拖拽**；Moe Avatar 是 **多帧 sheet + 走动**。正式养成走 Avatar；Flag 可回滚 A。
