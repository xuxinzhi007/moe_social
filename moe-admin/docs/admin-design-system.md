# Moe Admin V2 Design System

这份文档是 `moe-admin` 后续页面改版的统一参照。目标不是做“普通后台”，而是做一套有品牌识别、强信息层级、可持续扩展的运营控制台。

## 目标气质

- 关键词：`Cinematic Ops Console`、清晰、未来感、空间层次、轻盈但不花哨
- 基调：浅色控制台，叠加玻璃质感、柔和光晕、低对比网格背景
- 体验：高密度信息 + 明确操作反馈 + 统一动效节奏
- 禁止项：系统级图标禁止继续使用 emoji；不要为单页临时发明独立风格

## 核心原则

1. 所有页面优先复用统一组件，而不是局部手写样式。
2. 新页面必须从统一模板出发：`Hero -> Metrics -> Workbench/Panel -> Detail`。
3. 所有图标使用 `AdminIcon` 或品牌 SVG，不直接使用 emoji。
4. 动效以“进入、反馈、层级变化”为主，不做炫技式重动画。
5. 先保证统一，再追求花样。创新应建立在一套稳定系统上。

## 页面模板

每个主页面遵循以下结构：

1. `PageHero`
   页面名、描述、环境状态、主操作按钮、1 到 4 个关键信号。
2. `Insight Strip`
   指标卡、状态卡、趋势卡。支持 hover 抬升和边缘光。
3. `Workbench`
   主任务区。推荐使用双栏、分区卡片、表格+详情抽屉。
4. `Secondary Panels`
   快捷入口、提醒、时间线、发布流等辅助内容。

## 视觉 Token

- 背景：深海蓝偏冷色的渐变光感，主面板维持浅色阅读体验
- 主强调色：青蓝 `#3d8bfd`
- 次强调色：薄荷青 `#34d3c8`
- 能量点缀：暖金 `#f3b74f`
- 成功：`#34c38f`
- 警告：`#ffb648`
- 危险：`#ff6b6b`
- 圆角：大面板 `24px`，卡片 `20px`，控件 `14px`
- 阴影：柔和长阴影，不用传统重黑框

## 动效规则

- 页面进入：整体 `fade + translateY`
- 指标卡：逐个 `stagger`
- 导航项：hover 抬升 1px，激活项显示发光边
- 面板：hover 时边框高亮，不做大幅缩放
- 滚动区域：可使用顶栏模糊增强空间感
- 所有动效都必须考虑 `prefers-reduced-motion`

## AI 改版规则

以后无论谁修改 `moe-admin` 页面，都应遵守：

- 必须先查现有 `AppShell`、`PageHero`、`AdminIcon`、通用 panel/button/table 样式
- 新页面优先组合现有布局和组件
- 不能新增 emoji 侧栏图标或新的孤立色系
- 不能单独为某个页面写一套完全不同的 header / card / button 风格
- 如果确实需要新视觉组件，应先抽成复用组件再落页

## 分期建议

- 第一期：统一壳层、图标、首页、平台页、用户页
- 第二期：加入更完整的切页动效、滚动视差、图表动态主题
- 第三期：抽象完整设计 tokens 和组件文档，覆盖所有管理页面
