# 萌农场（QQ 农场玩法）功能文档

> 模块位置：`lib/game/farm/` + `lib/pages/pet/farm_page.dart`
> 状态：**v1 已完整实现并通过构建验证**（`flutter analyze` 0 issues / `flutter build web` 成功）
> 素材文档：[farm_asset_prompts.md](./farm_asset_prompts.md)

## 一、功能概述

从宠物房间「更多 → 萌农场」进入的独立全屏农场小游戏，复刻 QQ 农场核心循环，
与宠物养成系统共用金币经济，数据本地持久化（预留后端扩展）。

**核心循环**：买种子 → 种植 → 浇水加速 → 离线生长 → 收获 → 赚币 → 复购升级

## 二、玩法系统

### 2.1 网格与相机

- 6×8 网格（48 块地），tile 尺寸 128 逻辑像素
- (col, row) 逻辑坐标 ↔ 世界像素换算（`FarmGrid` 为 SSOT）
- 相机支持拖拽平移 + 自适应缩放，边界钳制

### 2.2 交互模式（轻量方案）

| 操作 | 行为 |
|------|------|
| 点击空地 | 弹出种子选择面板种植 |
| 点击生长中作物 | 浇水（当前阶段剩余时间 -30%，每株限 2 次） |
| 点击成熟作物 | 收获 |
| 长按任意地块 | 查看详情（作物/进度/剩余时间） |
| 道具待释放 | 点击地块对目标使用肥料 |

### 2.3 作物经济表

| 作物 | 种子价格 | 收获金币 | 净利润 | 生长总时间 |
|------|---------|---------|--------|-----------|
| 小萝卜 radish | 5 | 12 | +7 | ~1.5 min |
| 胡萝卜 carrot | 10 | 25 | +15 | ~7 min |
| 卷心菜 cabbage | 20 | 50 | +30 | ~20 min |
| 向日葵 sunflower | 50 | 130 | +80 | ~1 h |
| 草莓 strawberry | 100 | 280 | +180 | ~2 h |

生长模型采用「累计有效秒数」（progressSeconds），天然支持离线补长与加速。

### 2.4 爽感机制（全量实现）

| 机制 | 说明 |
|------|------|
| A 连收 Combo | 6s 窗口内连续收获，倍率递增（最高 +100%） |
| B 一键全收 | 底部按钮，错帧连续收割动画 |
| C 生长可视化 | 作物 scale 渐进 + 摇曳 + 阶段晋升弹跳 + 进度环 |
| D 稀有变异 | 金色 8%（×3 收益）/ 彩虹 2%（×5 收益），光晕特效 |
| E 加速道具 | 肥料（单株推进 30%，15 币）/ 阳光瓶（全体推进 20%，60 币） |
| F 收获飞币 | 金币抛物线飞向 HUD + 粒子特效 |
| G 每日首收 | 当日首次收获 ×2 奖励 + 庆祝横幅 |

### 2.5 经济与持久化

- 金币与宠物系统共用（`PetProvider.addCoins/spendCoins`）
- v1 纯本地：SharedPreferences JSON + 2s 防抖写入 + `saved_at` 时间戳离线补长
- 数据模型已按可对接后端设计（`toJson/fromJson` 完整）

## 三、代码架构

```
lib/
├── models/
│   ├── farm_crop_config.dart   # 作物/道具/变异配置 SSOT + 素材路径
│   └── farm_state.dart         # FarmGrid 网格常量 / FarmPlot / FarmState 存档
├── providers/
│   ├── farm_provider.dart      # 种植/浇水/收获/商店/道具/持久化/ticker
│   └── pet_provider.dart       # +addCoins / spendCoins / boostMood
├── game/farm/
│   ├── farm_game.dart          # FarmFlameGame 主类（世界/相机/特效 API）
│   ├── farm_tile_grid.dart     # 网格渲染 + 坐标换算 + 地块交互
│   ├── farm_crop_sprite.dart   # 生长动画/进度环/变异光晕/程序化回落
│   ├── farm_effects.dart       # 飘字/粒子/飞币/Combo 横幅
│   └── farm_hud.dart           # 金币胶囊 + 可收获提示条
└── pages/pet/
    ├── farm_page.dart          # 全屏农场页（交互分发 + 商店/种子/详情弹层）
    └── pet_home_page.dart      # 「萌农场」入口按钮
```

**素材回落机制**：所有素材加载走 `PetArt.loadImage`，缺图返回 null 时自动
切换程序化萌系绘制，保证无素材也可完整运行。
