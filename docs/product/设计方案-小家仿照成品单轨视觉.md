# 设计方案：小家「仿照成品」单轨视觉（止半成品感）

| 项 | 内容 |
|----|------|
| **日期** | 2026-08-01 |
| **目的** | 解释为何出现蓝块/不一致，并规定**一条可复刻的成品视觉轨** |
| **原则** | 对标成熟放置养成的**能力节奏与信息架构**，不抄资产/文案；App 正式渲染只认 **Paper PNG** |

---

## 1. 为什么现在像半成品？

| 现象 | 原因 | 定义外？ |
|------|------|----------|
| 蓝色方块 | `petMoeAvatar` 开了走 sheet，合成失败画蓝占位 | **是** · 调试占位进了正式屏 |
| 属性区过大/发白 | 布局未 `min` 或半透明底板过大 | **是** · HUD 未按「紧凑浮层」约束 |
| 两排按钮风格不一 | 次轨 pill + 主轨方键叠代未统一 Token | 半成品感来源 |
| 3D 房间 + 扁角色 | 背景与角色不同族 | 美术债，非逻辑 bug |
| 多套渲染并行 | Paper / Moe / LPC 抢默认 | **是** · 违反「一条正式链」 |

**结论**：不是「仿成品仿不像」，而是**实验轨污染正式屏** + **HUD 未收敛**。

---

## 2. 仿照成品时仿什么（合法）

对标竖屏放置养成（如宠我一生类）的**可感知结构**，不是像素抄袭：

```text
┌─────────────────────────────┐
│ 返回   名称     货币        │  ← 顶栏轻
│ [场景Tab 客厅|院子|卧室]     │
│ 属性三行（紧凑·不挡脸）       │
│                             │
│      ★ 完整角色 + 家 ★      │  ← 绝对主角 ≥55%
│                             │
│ 次操作：换装 布置 商店（小）  │
│ 主操作：喂食 陪伴 更多（大）  │  ← 同圆角同阴影语言
└─────────────────────────────┘
```

必须像成品的 5 条：

1. **角色永远完整**（禁止蓝块/灰块占位上正式屏）  
2. **家是布好的**（有地毯/家具比例，不是空舞台）  
3. **主操作只有 3 个大键**  
4. **一套按钮语言**（主次尺寸不同，但同一圆角/描边/字体）  
5. **反馈暖色气泡**（无系统黑条）

---

## 3. 工程单轨（已开刀）

| 项 | 规定 |
|----|------|
| 正式渲染 | **Paper PNG**（`petMoeAvatar=false`，`petLpcPrototype=false`） |
| sheet 失败 | 回落 Paper，**禁止**蓝矩形 |
| 属性条 | `mainAxisSize: min` + 紧凑底板 |
| Moe/LPC | 仅 Flag 调研，过线前不得默认开 |

---

## 4. 下一波优化顺序（仿成品，不并行乱改）

1. **验收 W0**：热重启后必须是完整小萌，不是蓝块  
2. **统一底栏 Token**：主轨三键样式为唯一规范；次轨若保留，高度 60%、同圆角  
3. **家具尺度**：相对角色放大，进门像家  
4. **背景去水印 / 同族平涂**（美术）  
5. **服装每槽≥3**（内容，仍走 Paper）

---

## 5. 给 UI 的一句话 brief

> 竖屏放置养成小家：舞台主角是「完整 Q 版角色 + 已布置房间」；HUD 轻、主操作三键、次操作更小；禁止占位色块与两套完全不同的按钮皮肤同时出现。
