# 回复参谋贴纸桌宠悬浮层 — 设计纪要（2026-11-05）

> 已拍板 UX。球侧当场闭环为主；无大卡 / 大半屏。  
> 技术落地见 [../specs/reply-assist-overlay-pet-tech-eval-2026-11-05.md](../specs/reply-assist-overlay-pet-tech-eval-2026-11-05.md)。  
> 产品总案见 [reply-assist-screen-read-2026-11-05.md](./reply-assist-screen-read-2026-11-05.md)。

## 1. 目标

用户在微信聊天页卡壳时，不离开当前 App，点一下桌宠小脸即可：**读屏 → 判断 → 三条可复制草稿**。只复制、不代发。小脸可拖，可当迷你桌宠。

## 2. 视觉

| 项 | 规格 |
|----|------|
| 形态 | 暖纸底圆形贴纸小脸，不是紫块圆球 |
| 尺寸 | 约 40–44dp，不挡正常点按聊天 |
| 主色 | `#5E6AD2` 仅小面积（复制芯片、状态点） |
| 层次 | 暖纸 `#FBF6EE` / 近白气泡 / 轻阴影；萌系，不工具风 |
| 表情 | 见 §5；**不**绑 moe-avatar 养成包 |

## 3. 状态机

```text
待命 idle ──点脸──► 听 listening ──读到字──► 想 thinking
                      │                         │
                      │空树/非微信               │suggest 返回
                      ▼                         ▼
                 降级 fallback              出选项 ready
                                                │
                                           点「复制」
                                                ▼
                                           复制成功 success
                                                │
待命 ◄──再点脸 / 点空白收回── 出选项 / 成功 / 降级
拖动在任意态可用（超过 touch slop 不算点按）
听/想期间再点脸：忽略或轻提示「还在看」，不重入
```

| 状态 | 脸 | 气泡 | 用户可做 |
|------|----|------|----------|
| **待命 idle** | 安静小脸 | 无 | 拖；单击开始读屏 |
| **听 listening** | 专注/睁眼 | 「正在看聊天…」+ 点点 | 拖；不可重入 |
| **想 thinking** | 思考 | 「想怎么回比较安心…」+ 点点 | 拖；不可重入 |
| **出选项 ready** | 浅笑 ready | 最多 3 条选项气泡，每条带「复制」 | 拖；复制；再点脸或点空白收回 |
| **复制成功 success** | 开心 | 「已复制 · 去贴就好」；选项可仍在 | 再复制其它条；点脸收回 |
| **降级 fallback** | 为难 | 读空 / 非微信 / Flutter 未起 的短文案 | 点脸收回；引导去 App 贴图 |

听 → 想：读树成功后立刻切。想 → 出选项：suggest 返回后先轻动画（脸 ready + 气泡 fade），再弹出选项。不做大卡、不做判断摘要半屏。

## 4. 拖动与点按

- **拖**：按住小脸移动整层（脸+当前气泡）。松手后夹在屏幕内；可停在角落。
- **点**：位移未超过系统 touch slop → 单击。待命=展开流程；已展开选项/成功/降级=收回只留小脸。
- **气泡复制**：命中选项条或「复制」芯片 → 写入系统剪贴板，**不**走无障碍 tap/type，**不**代发。
- 展开后微信聊天区仍可点（不设全屏挡板）。点空白收回靠 `ACTION_OUTSIDE`，不拦截微信手势。

## 5. 表情清单（MVP）

| 键 | 何时 | 画法（Canvas/drawable，非养成包） |
|----|------|----------------------------------|
| `idle` | 待命 | 细眼、浅笑、淡腮红 |
| `listening` | 读树 | 圆眼、略看向气泡 |
| `thinking` | 等 suggest | 眯眼、小口 |
| `ready` | 选项出现 | 弯眼浅笑 |
| `success` | 刚复制 | 闭眼笑（^_^） |

听/想气泡带三点循环。不做 Spine / moe-avatar 换装。

## 6. 与 App 面板的关系

| 能力 | 在哪 | 说明 |
|------|------|------|
| 当场读屏 + 三条复制 | **悬浮层** | 主路径；不跳回 App |
| 开无障碍 / 悬浮窗权限 | App 回复参谋页 | 悬浮层不负责引导系统设置 |
| 显示/隐藏桌宠 | App 回复参谋页 | 开关贴纸层，不是开关自动化 |
| 粘贴长文 / 相册截图 / 判断摘要 | App 面板 | 长编辑与降级输入 |
| 空树 / 非微信 / 引擎未起 | 悬浮层短气泡 + 必要时 Toast | 引导「去 App 贴图」或「先打开 Moe」 |
| 识图 OCR | App 截图路径（本轮 stub） | 悬浮层只展示 fallback 态 |

**降级才进 App**：树可读且 Flutter 在线时，结果只出现在气泡。用户没有被强迫切回 Moe 看大卡。

## 7. 硬禁

- 代发、后台连续偷读、全机无白名单读屏。
- 启用 AutoGLM 的 tap/type/手势。
- 用大半屏卡片挡住微信。

## 8. 验收（产品）

- 紫块圆球被贴纸小脸替换；可拖；点开/再点收回。
- 听/想有小气泡或点点 + 表情切换。
- 有结果时 3 条可单独复制；复制后有轻反馈。
- 空树有 fallback 交互态。
- 未登录 / Flutter 未起：Toast 或短气泡，不崩。
