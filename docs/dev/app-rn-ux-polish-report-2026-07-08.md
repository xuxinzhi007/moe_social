# App RN 样式与体验优化报告（持续更新）

## 目标

在 Flutter 向 `app-rn/` 迁移期间，持续提升 React Native 版本的：

- 样式完成度
- 交互反馈
- 页面层级
- 视觉氛围
- 体验一致性

最终目标不是“能跑”，而是尽量接近现有 Flutter 正式版的产品感，并在可行处做额外优化。

## 已完成优化

### 1. 共享视觉骨架

已完成：

- 重建 `app-rn/src/theme/tokens.ts`
- 统一页面背景、柔和渐变氛围、玻璃卡片、圆角和分层阴影
- 重建 `Screen / Panel / ActionButton / MetricCard / AuthInput`

当前效果：

- RN 页面不再是深色占位版
- 页面基调已切到更接近 Flutter 的柔和、轻盈、卡片化风格
- 后续页面可以复用同一套视觉系统继续扩展

### 2. 导航体验

已完成：

- 重做 `app-rn/src/navigation/RootShell.tsx`
- 底部导航从纯文字/占位状态升级为浮层导航条
- 用几何图形替代临时字体 icon
- 增加激活态底部高亮条、背景高光和按压反馈

当前效果：

- 首页 / 聊天 / AI / 我的 四个主入口更像正式产品导航
- 底部导航的辨识度和完成度明显提升

### 3. 首页体验

已完成：

- 重做 `app-rn/src/features/home/HomeScreen.tsx`
- 增加首页 hero 区
- 增加 stories 风格的“今日灵感”区
- 增加热点 tag 区
- 增强动态卡片的信息层级
- 增强点赞反馈、内容类型 badge、快速入口卡片分区
- 补齐快捷卡片和动态操作的统一按压态
- 使用统一状态卡片承接加载中 / 空状态 / 错误提示

当前效果：

- 首页不再只是“接口数据展示”
- 已开始具备 Flutter 首页那种内容分发、轻推荐和互动入口的感觉
- 刷新、点赞、空状态的体验节奏更统一

### 8. 全局交互一致性整理

已完成：

- 新增 `app-rn/src/components/StatusNotice.tsx`
- 统一加载中 / 空状态 / 错误提示的卡片样式
- `ActionButton` 增加 `disabled` 能力，完善主次按钮阴影和按压态
- `Panel` 增加轻高光层，提升卡片通透感
- `MetricCard` 增加高光层，减少纯平面感

当前效果：

- 页面提示块不再散落为普通文案
- 按钮、卡片、表单滚动体验更统一
- 后续其他页面补齐时可以直接复用这一层
