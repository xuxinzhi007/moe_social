# 环境配置说明

## API 基址（Flutter App）

**唯一配置入口：** `lib/utils/config.dart`（`AppConfig.isProduction` / `developmentUrl` / `productionUrl`）。

`lib/services/api_service.dart` 在启动时通过 `initRemoteProductionBaseUrl()` 读取上述配置，**不要**再在 `api_service.dart` 里硬编码 `_isProduction` 或 cpolar 地址。

```dart
// lib/utils/config.dart
static const bool isProduction = false; // true = 线上 VPS；false = 本机/模拟器
static const String productionUrl = 'http://你的线上:8888';
static const String developmentUrl = 'http://127.0.0.1:8888';
```

| 模式 | 典型基址 | 说明 |
|------|----------|------|
| 本地开发 | `http://127.0.0.1:8888` | 模拟器可用 `10.0.2.2:8888`（Android） |
| 线上 | `productionUrl` | 真机 debug 若 `isProduction=true` 也会走线上 |

**真机连本机后端：** 将 `developmentUrl` 改为电脑局域网 IP（如 `http://192.168.x.x:8888`），并保持 `isProduction = false`。

穿透域名（cpolar / ngrok）若用于 `productionUrl`，`ApiService` 会自动附加隧道绕过头；隧道失效时请更新 `productionUrl`。

## 后端服务

| 服务 | 默认端口 | 说明 |
|------|----------|------|
| API | **8888** | `cd backend && make api` |
| RPC | **8080** | `make rpc` |
| llama-server | **6633**（示例） | `llm_inference.base_url`，见 [llm-inference-and-memory-vision.md](./llm-inference-and-memory-vision.md) |

端口全表：[ports.md](./ports.md)。

后端监听与 CORS 见 `backend/config/config.yaml`、`backend/api/etc/super.yaml`；**无需**为前端切换而改后端端口。

## 管理台（moe-admin）

开发：`cd moe-admin && npm run dev` → http://127.0.0.1:5173/ops/  
Vite 将 `/api/admin` 代理到 `:8888`；运维菜单需另开 `make deploy-agent`（:19010）。

## 验证

1. Debug 控制台查看 `API环境: local/online` 日志（`ApiService` 启动时输出）。
2. 调用登录或任意 API，确认请求 host 与预期一致。
3. 管理台：登录后打开「推理状态」等页，确认能连上 API。
