# 序列帧工作台升级目标

## 产品边界

工作台负责把来源不一致的图片整理成可交付的透明序列帧：帧池、效果/部件层、蒙版、统一画布、锚点、预览和 PNG + JSON 导出。Godot 继续使用自身的 `Sprite2D` / `AnimatedSprite2D` 与网格裁剪能力，不在管理台复制一套动画编辑器。

## 本次升级

### 效果与部件层

- 单张图片可以覆盖指定帧区间，适合攻击闪光、武器、阴影和命中特效。
- 多张图片按帧条从左到右映射，适合独立的攻击效果序列。
- 每层统一调整偏移、缩放、透明度和启用状态。
- 选中图层后可直接在统一画布拖动，控件与画布保持同步。
- 预览、导出 Sheet、JSON 和工作区保存使用同一层数据。
- 导出时将图层烘焙进最终 PNG，Godot 不需要理解管理台图层。

### 直接编辑序列帧

- 帧条从左到右同时决定编辑顺序、预览顺序和导出顺序；拖动帧卡片即可重排。
- 选中帧后可直接修改时长、缩放、X/Y 偏移、启用状态和透明蒙版；这些编辑只作用于当前帧。
- 画布拖动默认编辑统一锚点；选中效果/部件层后拖动画布编辑该层位置，避免把角色帧和特效位置混为一谈。
- 预览背景、蒙版、工作区和导出入口统一由正式工具面板管理，不再通过 DOM 注入控件。

### 角色模板校准

角色模板只定义固定画布、单帧尺寸、锚点和布局，并显示中心线/落脚基准线，用来校准比例与落脚点；选中的模板尺寸、锚点和 Fit 模式会同步到最终 PNG/JSON；模板不会对一张已经合并的 AI 图片自动拆分身体或重绘姿势。

如果需要单独调整手臂、武器、翅膀等部位，必须将部位作为透明图片单独导入效果/部件层。这样调整是可见、可控、可回退的，也不会破坏原始角色帧。

## 后续目标

### P1

- 统一基础帧池与效果/部件层的数据模型。
- 统一预览、测量和导出的变换语义。
- 工作区完整保存帧变换、模板、锚点、蒙版和图层。
- 增加模板基准线、脚底线和安全框的可视化校准。

### P2

- 项目文件与可恢复历史。
- 多动作批处理和图层复用。
- 直接 PNG/JSON 导出与批量校验。
- 大图与多图层场景的性能优化。

## 验收标准

1. 添加的效果层在预览中出现，并与导出的 PNG 位置一致。
2. 单图层只出现在配置的帧区间，多图层序列按帧条顺序播放。
3. 调整模板只改变统一画布和锚点，不修改源帧像素。
4. 保存并恢复工作区后，帧顺序、帧变换、蒙版、模板和图层参数一致。
5. 输出 PNG + JSON 能被 Godot 原生网格裁剪并按从左到右播放。
