最近 API 请求（真实 request/response）

何时写入记忆库？（当前实现）

触发时机每轮聊天 AI 回复成功后（已登录）
heuristic_extract用户句匹配：我改名叫 / 叫我 / 请记住我叫 / 记住：我喜欢… → 立即 upsert
tag_extract用户或 AI 文本含 [记忆:内容] → upsert
llm_extract_client中转模型（失败回退 Ollama）分析对话 JSON → upsert
不写入你现在叫xxx（改 AI 角色名）、纯闲聊、提取返回 []
device_sync设备同步，展示层过滤，不计入 display total

何时读取记忆？

默认（路径 A）发消息前 GET /memories/search?q=用户本句 → 混合检索注入（+0 次聊天）
向量索引记忆 upsert 后异步 embed；无索引时 search 自动 rebuild；可 POST /memories/reindex
高级（路径 B）tools：memory_search / memory_list?query= / memory_get 等
