# 灵活脚本编辑方案

## 跨应用执行

**已支持。** 无障碍服务操作的是「当前屏幕前台」，与是否在 Moe Auto 内无关。

典型跨应用脚本：

```json
{ "action": "launch", "package": "com.tencent.mm" },
{ "action": "wait", "ms": 2000 },
{ "action": "ocr_click", "text": "发现", "timeout_ms": 8000 }
```

| 动作 | 跨应用 |
|------|--------|
| launch | 拉起任意已安装 App |
| tap / swipe / click_text / ocr / click_image | 对前台界面生效 |
| back / home | 系统级 |

限制：需用户已授权无障碍；部分系统界面可能无法操作。

## 步骤列表（可随意调整）

| 入口 | 能力 |
|------|------|
| **向导创建** | 录步骤 + 列表上移/下移/删除 |
| **编辑步骤**（用户脚本） | 加载已有步骤 + 排序/删除/编辑 + 追加 launch/等待 |
| **JSON 高级** | 右上角 `{ }` 进入原始 JSON |

数据模型：`List<ScriptStep>` ↔ JSON `steps[]`，保存时统一序列化。

## 已实现（扩展）

- **已安装应用选择器**：启动应用步骤可搜索、列表选择
- **定时任务**：脚本页 → 定时任务；每天/每周/一次；可选「运行脚本 / 打开应用」；`AlarmManager` + 开机恢复
- **运行当前步骤**：运行 Tab 显示步骤进度；高级设置可开通知栏步骤
- **屏幕点击指示**：默认开启，可在高级设置关闭

## 后续可增强

- 拖拽排序（当前为上移/下移按钮）
- 录制 Tab：边操作边追加步骤
- 条件分支 / 循环：扩展 DSL 与流程图
- 运行历史：每次执行记录步骤快照（与编辑列表分离）
