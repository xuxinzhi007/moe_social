# 识屏与识图（当前实现）

## 设计原则

- **不强制登录**：脚本、模板、日志均存本机。
- **JSON 脚本**：用户可自由编写、导入，无云端依赖。

## 三种定位方式

| 方式 | 原理 | 自由度 | 实用性 |
|------|------|--------|--------|
| `click_text` | 无障碍节点树找字 | 中：仅 App 暴露的文字 | 高：稳定、快 |
| `ocr_click` | 无障碍截图 + ML Kit 中文 OCR | 高：屏幕上可见即可 | 中高：游戏/自绘 UI 可用，受字体/对比度影响 |
| `click_image` | 截图 + 灰度模板匹配（NCC） | 高：任意 PNG 模板 | 中：图标/按钮好用；动画、半透明、大幅缩放会失败 |

## 识图流程（`click_image`）

1. 无障碍服务 `takeScreenshot()`（**需 Android 11+**）
2. 读取脚本引用的 PNG（`user_scripts/templates/`）
3. 屏幕缩放到最长边 480px，模板缩放到 120px（**内部自动缩放，用户不手动调**）
4. 滑动窗口 + 归一化互相关（NCC）找最高分
5. **多尺度**：在 `scale_min`～`scale_max` 范围内尝试多个模板尺寸（应对分辨率差异）
6. 分数 ≥ `threshold`（默认 0.82）则点击中心点

## 局限（诚实说明）

- 不是 OpenCV 级鲁棒匹配；复杂背景、动态画面、3D 效果易误匹配。
- 截图不能替代用户「在别的 App 里手动调 UI 大小」——裁剪在 **识图工具** 里用滑块选区域。
- Android 10 及以下无系统截图 API，OCR/识图不可用。

## 推荐用法

1. 用 **识图工具** 截取小区域（只框图标，不要整屏）
2. `threshold` 从 0.82 起，误点则提高到 0.88～0.92
3. 文字按钮优先 `click_text`，不行再用 `ocr_click`
4. 图标/固定素材用 `click_image` + 多尺度参数
