# 院子种菜素材

来源：桌面 `动漫角色/flutter角色图`，接入后统一英文蛇形文件名。

| 文件 | 用途 |
|------|------|
| `soil_plot.png` | 耕好地皮 |
| `grass_tile.png` | 草地砖（备用） |
| `yard_bg.png` | 同步到 `room/yard_bg.png` |
| `yard_plots.png` | 整院四坑参考图（备用） |
| `seed_bag.png` | 空地提示 / 种子袋装饰 |
| `seed_shop.png` | 院子种子小屋装饰 |
| `crop_sprout.png` | 初苗（seed） |
| `crop_grow.png` | 中期苗（sprout） |
| `crop_ripe.png` | 成熟可收（ripe） |
| `coin.png` | 货币备用 |

渲染时对黑底 PNG 走 `PetArt.loadImage(..., knockoutDarkBg: true)`。
