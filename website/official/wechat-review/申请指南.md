# Moe Social · 微信开放平台申请资料整理

本文档汇总 **移动应用 + 微信登录（OAuth）** 在开放平台的填写项、工程对应关系与本地生成命令。  
产品官网部署说明仍见 [`../README.md`](../README.md)。

---

## 一、你在申请什么？

| 概念 | 说明 |
|------|------|
| **移动应用** | 在微信开放平台创建的应用类型，获得 **AppID / AppSecret** |
| **微信登录** | 移动应用开通的能力；App 内通过 `fluwx`（Open SDK）唤起微信授权 |
| **不是** | 把 App 上架到微信、也不是小程序 |

审核主要看：**应用说明、官网、流程图/截图、包名与签名** 等材料，不一定会安装你的 APK。

## 六、应用图标

### 6.1 各尺寸用途（不必全部上传微信）

| 用途 | 路径 / 命令 | 说明 |
|------|-------------|------|
| **微信开放平台** | `website/official/wechat-icons/` 下 **28×28**、**108×108** | 仅这两张在平台上传；由 1024 主图缩放，与 App 一致 |
| **Flutter 源图** | `assets/branding/app_icon.png`（1024） | `flutter_launcher_icons` 输入 |
| **iOS 桌面** | `ios/Runner/Assets.xcassets/AppIcon.appiconset/` | 无 28 槽位；最近为 **29×29@1x** |
| **Android 桌面** | `android/app/src/main/res/mipmap-*/ic_launcher.png` | 5 档密度，脚本自动写入 |

### 6.2 生成命令（Windows 推荐）

```powershell
# 1. 主图 + 微信 28/108 + Android mipmap
powershell -ExecutionPolicy Bypass -File website/official/scripts/generate_wechat_icons.ps1

# 2. iOS / Web / Windows / macOS 启动图
dart run flutter_launcher_icons
```

仅刷新微信两张图（已有 `assets/branding/app_icon.png`）：

```powershell
powershell -ExecutionPolicy Bypass -File website/official/scripts/generate_wechat_icons.ps1 -WechatOnly
```

然后在开放平台对 28 / 108 **重新上传**（平台不会自动同步本地文件）。

Python 版（需 `pip install pillow`）：`website/official/scripts/gen_wechat_icons.py`

## 七、Android 平台信息（填写应用平台信息）

### 7.1 表单怎么选

| 字段 | 建议 |
|------|------|
| 开发 Android 应用 | **是** |
| 开发方式 | **传统模式开发**（SDK / fluwx） |
| 应用已上架 | **否**（未上应用商店） |

未上架时微信登录等能力有 **每日约 100 次** 量级限制，开发自测一般够用；上架后可改为「是」并填商店链接。

### 7.2 包名与签名（两套，不要混用）

生成证书方式与微信文档一致（`keytool -genkey` → `.jks`），但 **debug 与 release 是不同文件，签名不同**。

| 构建 | 包名 | 证书 | 应用签名（MD5，32 位小写） |
|------|------|------|---------------------------|
| **Debug**（`flutter run`） | `com.example.moe_social.dev` | `%USERPROFILE%\.android\debug.keystore` | `47398d3e6b670482ab1569276ae6cf8b` |
| **Release**（`flutter build apk --release`） | `com.example.moe_social` | `android/app/release.jks`，alias `key` | `a2d2557915471cf02725d1cfb33fcbbd` |

**当前真机调试**：开放平台填 **Debug 包名 + Debug 签名**。

**建议**：用微信提供的 **签名生成工具**（在已安装对应 APK 的手机上输入包名）核对；若与上表不一致，**以工具为准**。

查看 release 证书信息：

```powershell
keytool -list -v -keystore android/app/release.jks -alias key -storepass <你的密码>
```

`release.jks` 与密码勿提交公开仓库；丢失后无法用同一签名更新已上架应用。

## 九、代码与配置对应关系

```
用户点击「微信登录」
  → fluwx（WechatConfig.appId）
  → 后端 authorize URL（flow=app）
  → 微信授权
  → GET /api/auth/wechat/callback
  → wechatloginlogic 换 token、建号/登录
```

| 文件 | 作用 |
|------|------|
| `lib/utils/wechat_config.dart` | 客户端 AppID、`oauthFlow: app` |
| `lib/services/wechat_sdk_service.dart` | fluwx 注册与授权 |
| `backend/config/config.yaml` | `wechat.enabled`、`wechat.app`、`redirect_uri` |
| `backend/utils/wechat_oauth*.go` | 授权 URL、回调、flow 分流 |

**注意**：`redirect_uri` 须与开放平台移动应用/网站应用配置的回调一致；改 VPS 配置后需重启服务。

Web 端扫码登录使用 **网站应用**（`wechat.website`），与 App 移动应用 **不同 AppID**，勿混用。

## 十、常见问题

| 现象 | 可能原因 |
|------|----------|
| 微信登录未启用 | VPS `wechat.enabled: false` 或未同步 config |
| 授权失败 errCode -6 | 包名或 **应用签名** 与开放平台登记不一致；或用了小程序/公众号 AppID |
| 请在微信客户端打开 | 用错了公众号网页授权链接；App 应走移动应用 + fluwx |
| 平台图标仍是旧的 | 需在开放平台 **重新上传** PNG，不会读你电脑本地目录 |
| 108 图只显示「Mo」 | 已改为从 1024 主图缩放；请重新跑脚本并上传 |

## 十二、一次性操作顺序（建议）

1. 跑图标脚本 + `dart run flutter_launcher_icons`
2. 部署 / 确认官网 HTTPS 可访问
3. 截 `app-flow.html` + 2～3 张真机截图
4. 开放平台填写资料、上传图标与流程图、粘贴申请说明
5. Android 填 **debug 包名 + 签名**（当前 `flutter run`）
6. 管理员微信扫码提交
7. 审核通过后：把 **移动应用 AppID/Secret** 写入 `wechat_config.dart` 与 VPS `config.yaml`，重启后端，真机再测微信登录
8. 上架前：在平台补充 **release 包名 + release 签名**
