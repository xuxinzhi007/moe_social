# Animation Sheet Skill

## Purpose

将 AI 生成或用户提供的无规则图片/视频帧，整理为可被任意 2D 工具或引擎使用的透明网格序列帧图。

## Non-Negotiable Boundaries

- 编辑器不绑定 Godot、LPC、Unity 或其他消费端。
- 输入支持 PNG、JPG、JPEG 和本地视频。
- JPG/JPEG 只作为输入格式，导出统一为 RGBA PNG。
- 原始帧池和动画行必须分离。
- 从动画行移除帧，不得误删帧池中的原始帧。
- 从帧池删除帧时，必须同步清理所有动画行引用。
- 不用复制、往返或静态变换冒充真实新动作；这类结果必须标记为草稿。
- 不添加没有完整产出和验证闭环的 UI 功能。

## Canonical Workflow

```text
导入 PNG/JPG/视频
→ 提取和编号原始帧
→ 统一 cell 尺寸、缩放、偏移和锚点
→ 建立动画行
→ 将帧加入/移出动画行
→ 调整动画行顺序、FPS 和循环
→ 预览每个动画行
→ 合并透明网格 PNG
→ 导出通用 animation manifest
```

## Animation Row Contract

每个动画行至少包含：

- 稳定 `id`
- 显示名 `label`
- `row`
- 帧索引列表
- `fps`
- `loop`

输出 manifest 使用 `sprite-animation-v1`，只描述图片网格布局，不描述任何引擎 API。

## Editing Rules

1. 导入时保留文件名和原始帧顺序。
2. 任何帧都可以被多个动画行复用。
3. 动画行内部排序不应改变帧池索引。
4. 删除帧池帧后，后续索引必须安全重映射。
5. JPG 背景不自动假设为透明；需要用户明确执行背景清理并检查结果。
6. 每次导出必须生成一张完整网格 PNG，不能只导出散乱帧。

## Acceptance Checklist

- [ ] PNG、JPG、JPEG 都能导入。
- [ ] 视频可抽帧并进入帧池。
- [ ] 可以创建至少两个动画行。
- [ ] 可以从动画行移除帧而不影响其他动画行。
- [ ] 可以从帧池删除帧并安全清理引用。
- [ ] 每个动画行可独立设置 FPS 和循环。
- [ ] 输出 PNG 为统一 cell 尺寸的透明网格。
- [ ] 输出 manifest 能解释每一行动画的位置和帧数。
- [ ] 至少用一个真实项目素材完成导入、调整、导出回归。

## Definition Of Done

只有当真实素材完成“导入 → 调整 → 网格导出 → 外部工具读取”闭环后，才允许把本能力标记为完成；否则只能标记为实验或草稿。
