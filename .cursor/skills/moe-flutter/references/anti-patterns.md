# Flutter Anti-Patterns — Named Tells

The most reliable signals that a Flutter UI was generated by an AI on autopilot. Every pattern below is a **tell** — avoid them all.

---

## 1. Hardcoded colour values

**The tell:** `Color(0xFF6200EE)`, `Colors.blue`, `Colors.grey[300]` scattered through widget code.

**Why it's slop:** The project has MoeTokens as SSOT. Hardcoded colours bypass the design system, create visual inconsistency, and make dark-mode/theming impossible.

**Fix:** Every colour must reference `MoeTokens.primary`, `MoeTokens.surface1`, `MoeTokens.titleText`, etc. If a needed colour doesn't exist in MoeTokens, add it there first.

**Severity:** Critical.

---

## 2. Magic number spacing

**The tell:** `EdgeInsets.all(16)`, `SizedBox(width: 12)`, `Padding(padding: EdgeInsets.symmetric(horizontal: 20, vertical: 8))` with arbitrary numbers.

**Why it's slop:** MoeTokens provides a 4px-grid spacing scale (`spaceXs` through `space4xl`). Magic numbers break the rhythm and make the spacing system meaningless.

**Fix:** Use `MoeTokens.spaceSm`, `MoeTokens.spaceMd`, etc. Every spacing value must map to the token scale.

**Severity:** High.

---

## 3. Default Material chrome

**The tell:** Plain `AppBar()`, `Card()`, `ListTile()`, `ElevatedButton()` with no visual customization.

**Why it's slop:** Default Material widgets carry Google's visual language, not your app's. An unstyled `AppBar` is the fastest way to make an app look like a template.

**Fix:**
- `AppBar` → set `backgroundColor: MoeTokens.surface1`, `elevation: 0`, `surfaceTintColor: Colors.transparent`, custom `shape` with `surfaceBorder`.
- `Card` → replace with `Container` + `BoxDecoration` using `MoeTokens.shadowCard()` + `surfaceBorder` + `MoeTokens.radiusXl`.
- `ElevatedButton` → replace with `Container` + `MoeTokens.gradientPrimary` + `shadowGlow` for CTAs.
- `ListTile` → custom row with explicit MoeTokens spacing and typography.

**Severity:** High.

---

## 4. Identical page templates

**The tell:** Every page follows the same `Scaffold → AppBar → ListView/Column → children` rhythm.

**Why it's slop:** Structural monotony is the core AI tell. If every page has the same skeleton, the app feels like one screen repeated.

**Fix:** Use different scroll models and layout patterns. See [`layout-patterns.md`](layout-patterns.md). A chat page should feel structurally different from a profile page, which should feel different from a feed page.

**Severity:** Critical.

---

## 5. Generic empty states

**The tell:** A centered `Icon` + `Text('No data')` with no visual treatment.

**Why it's slop:** Empty states are a design opportunity, not an afterthought. A bare icon + text screams "I didn't think about this."

**Fix:** Use a gradient icon container (`MoeTokens.gradientSoft`), two-line text hierarchy (`MoeTokens.titleText` + `MoeTokens.hintText`), and optionally a CTA button with `gradientPrimary`.

**Severity:** Medium.

---

## 6. Single-layer shadows

**The tell:** `BoxShadow(blurRadius: 10, color: Colors.black12)` — one shadow, everywhere.

**Why it's slop:** Real depth comes from layered shadows. MoeTokens provides `shadowSm()`, `shadowCard()`, `shadowElevated()`, `shadowGlow()` — each tuned for a specific elevation level.

**Fix:** Use the appropriate MoeTokens shadow for the elevation context. Cards get `shadowCard()`, small items get `shadowSm()`, dialogs get `shadowElevated()`, CTA buttons get `shadowGlow()`.

**Severity:** Medium.

---

## 7. Inconsistent border radius

**The tell:** Some cards use `BorderRadius.circular(12)`, others `16`, others `20` — no pattern.

**Why it's slop:** Random radii create visual noise. MoeTokens provides a deliberate scale from `radiusSm` (8) to `radius2xl` (24).

**Fix:** Use semantic radius tokens — `radiusSm` for chips/badges, `radiusMd` for small cards, `radiusLg` for standard components, `radiusXl` for cards, `radius2xl` for large containers.

**Severity:** Medium.

---

## 8. Inline text styles

**The tell:** `TextStyle(fontSize: 16, fontWeight: FontWeight.w600, color: Colors.black)` scattered in widget code.

**Why it's slop:** Bypasses the MoeTokens typography scale. Creates inconsistency between similar text elements.

**Fix:** Use `MoeTokens.text*` for sizes, `MoeTokens.fontWeight*` for weights, `MoeTokens.titleText`/`bodyText`/`hintText` for colours.

**Severity:** High.

---

## 9. Missing surface borders

**The tell:** White cards on white backgrounds with only shadow for separation.

**Why it's slop:** Shadow-only separation looks muddy on light backgrounds. MoeTokens provides `surfaceBorder` (primary @ ~8% opacity) for subtle, cohesive edge definition.

**Fix:** Add `Border.all(color: MoeTokens.surfaceBorder)` to cards, containers, and elevated surfaces.

**Severity:** Medium.

---

## 10. No gradient variety

**The tell:** Every accent element uses the same `gradientPrimary`, or worse, no gradients at all.

**Why it's slop:** MoeTokens provides four gradients for different purposes: `gradientPrimary` (CTAs), `gradientSoft` (decorative), `gradientKawaii` (brand), `gradientText` (text via ShaderMask). Using only one or none wastes the visual vocabulary.

**Fix:** Match gradient to purpose. Primary actions → `gradientPrimary`. Decorative backgrounds → `gradientSoft`. Brand moments → `gradientKawaii`. Gradient text → `gradientText` via `ShaderMask`.

**Severity:** Low.

---

## 11. Flat interactive elements

**The tell:** Buttons and tappable areas with no visual feedback, no press animation, no hover state.

**Why it's slop:** Interactive elements should feel alive. MoeTokens provides `motionPressScale` (0.97) for press feedback and `motionFast` (160ms) for response time.

**Fix:** Wrap tappable widgets with a `GestureDetector` or custom button that scales to `MoeTokens.motionPressScale` on tap, with `MoeTokens.motionFast` duration.

**Severity:** Medium.

---

## 12. Glassmorphism without purpose

**The tell:** `BackdropFilter` with blur on every surface, creating visual noise without hierarchy.

**Why it's slop:** Blur is a hierarchical tool — it signals "this is floating above everything." Overusing it flattens the depth it's meant to create.

**Fix:** Reserve `blurHeavy` for dialogs/sheets, `blurMedium` for floating cards, `blurLight` for nav bars. Most surfaces should be opaque with `MoeTokens.surface1`.

**Severity:** Low.

---

## 13. Invented metrics and fake content

**The tell:** "+47% engagement", "50,000+ users", fake testimonials, placeholder avatars with initials that don't match.

**Why it's slop:** Fabricated content is one of the most obvious AI tells. Users notice immediately.

**Fix:** Use real data, or use honest placeholders: `'—'` with a grey label, `'Coming soon'`, or omit the section entirely.

**Severity:** Critical.

---

## 14. Italic headings

**The tell:** `TextStyle(fontSize: 24, fontWeight: FontWeight.bold, fontStyle: FontStyle.italic)` for section titles.

**Why it's slop:** Italic headings are a reliable AI-generated design tell. They look affected and break the typographic rhythm.

**Fix:** Headings are always roman (`fontStyle` not set). Carry emphasis with weight (`fontWeightDisplay`/`fontWeightTitle`), accent color (`MoeTokens.primary`), or gradient text.

**Severity:** Medium.

---

## 15. Animation overload

**The tell:** Every widget animates in with a different curve, duration, and direction.

**Why it's slop:** Excessive motion is distracting and performance-heavy. MoeTokens provides a disciplined motion system for a reason.

**Fix:** Use `MoeTokens.motionFadeDuration` (300ms) + `motionStaggerStep` (60ms) + `motionFadeOffset` (30dp) for list/block reveals. Use `motionFast` for press feedback. Use `motionMedium` for page transitions. Cut motion before adding it.

**Severity:** Medium.

---

## 16. SingleTicker + 多个 AnimationController

**The tell:** `with SingleTickerProviderStateMixin` 的 State 里创建了 ≥2 个 `AnimationController`（或多次 `createTicker`）。

**Why it's a crash:** Flutter 运行时断言：`SingleTickerProviderStateMixin but multiple tickers were created`。`flutter analyze` **抓不到**；进页即红屏。

**Fix:** ≥2 个 controller → 改用 `TickerProviderStateMixin`。接 Canvas/地图/粒子进主路径前数一遍 controller，并冒烟进页。

**Severity:** Critical（运行时硬崩）。
